# Political Rivalry

Геополитический симулятор в браузере: управление государством, экономикой, политикой, дипломатией и обществом.

## Возможности

- 🏛️ Создание собственного государства: название, флаг, столица, форма правления, идеология
- 👥 Правительство: президент, министры, партии, парламент, коалиции, выборы, импичмент
- 📜 Законы и реформы: 16 законов с модификаторами и взаимоисключениями
- 💰 Экономика: ВВП, бюджет, налоги, долг, инфляция, безработица, ЦБ, валюта, торговля, госпредприятия
- 👨‍👩‍👧 Демография: рождаемость, смертность, миграция, образование, здравоохранение, преступность
- 🌍 Дипломатия: отношения с 11 ИИ-странами, торговые соглашения, союзы, санкции, саммиты
- ⚔️ Армия: численность, бюджет, промышленность, боеготовность, договоры
- 🎲 Случайные события: 14 сценариев с выборами и последствиями
- 📊 Статистика: HDI, индекс демократии, 6 рейтингов, графики, историческая таблица

## Технологии

- **Backend:** Node.js + Express
- **Frontend:** Vanilla JavaScript (ES Modules), HTML5, CSS3
- **Без зависимостей на фронте** — только стандартные Web API (Canvas для графиков)
